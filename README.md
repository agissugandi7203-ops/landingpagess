# landingpagess

Leon Vasari — Curved VHS Film Archive (single-file HTML, CSS, and vanilla JavaScript).

## Deploy to Vercel

1. Import this repository in [Vercel](https://vercel.com/new).
2. Set **Framework Preset** to `Other` (no build command required, output directory `.`).
3. `vercel.json` handles clean URLs, routing, and security headers automatically.
